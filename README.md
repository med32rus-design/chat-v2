# Чат v2 — Улучшенный сайт для общения

Современный чат с WebSocket, реакциями и красивым интерфейсом.

## 🚀 Быстрый деплой на Koyeb

1. Зарегистрируйтесь на [koyeb.com](https://koyeb.com) через GitHub
2. Нажмите **Create App** → **Deploy with GitHub**
3. Выберите этот репозиторий
4. В **Environment variables** добавьте: `PORT=8000`
5. Нажмите **Deploy**
6. Готово! Сайт доступен через 1-2 минуты

## 🛠️ Локальный запуск

```bash
npm install
npm start
```

Откройте http://localhost:3000
